# Contributing to UNTRAPD

Thank you for wanting to contribute! 🎉

## Community-First Approach

UNTRAPD is not a traditional open-source project. We're building a family of like-minded people creating tools for living UNTRAPD.

## How to Contribute

### 1. Join the Community
- **Discord**: [Coming soon]
- **Introduce yourself**: Share your UNTRAPD journey
- **Get to know us**: Understand our values and approach

### 2. Find Something to Work On
- **Good First Issues**: Tagged with `good-first-issue`
- **Help Wanted**: Tagged with `help-wanted`
- **Your Ideas**: Propose new features or tools

### 3. Contribution Process

**Before starting**:
1. Comment on the issue to claim it
2. Discuss approach in Discord or issue comments
3. Wait for maintainer approval before significant work

**Development**:
1. Fork the repository
2. Create a feature branch: `feature/your-feature-name`
3. Make your changes (follow project conventions)
4. Test thoroughly
5. Commit with clear messages

**Submitting**:
1. Push to your fork
2. Open Pull Request with description:
   - What problem does this solve?
   - How did you test it?
   - Screenshots (if UI changes)
3. Respond to feedback
4. Celebrate when merged! 🎉

### 4. Code Standards

**General**:
- Write clear, readable code
- Add comments for complex logic
- Follow existing patterns in the project
- Include tests for new features

**Commit Messages**:
```
type: brief description (50 chars or less)

Longer explanation if needed (72 chars per line).

Examples:
- feat: Add dark mode toggle to settings
- fix: Resolve login redirect issue
- docs: Update installation instructions
- refactor: Simplify authentication flow
```

### 5. Getting Help

**Stuck?** Ask in:
- Discord #help-wanted channel
- Issue comments
- Pull request discussions

**No question is too small.** We're here to help! 💜

## What We're Looking For

**Great contributions**:
- ✅ Solve real problems for the community
- ✅ Align with UNTRAPD values
- ✅ Include documentation
- ✅ Are well-tested

**Avoid**:
- ❌ Premature optimization
- ❌ Overly complex solutions
- ❌ Breaking changes without discussion
- ❌ Contributions without context

## Recognition

Contributors are recognized through:
- Contributor credits in README
- Shoutouts in Discord (when available)
- Profile on contributors page (when created)
- Revenue sharing (for community marketplace items)
